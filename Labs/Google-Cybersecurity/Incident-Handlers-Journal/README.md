# Incident Handler's Journal — Google Cybersecurity Professional Certificate

## Project Description

An ongoing journal, following the template provided in the Google
Cybersecurity Professional Certificate, used to record findings
after completing an activity and to log key takeaways about
cybersecurity tools or concepts encountered throughout the course.
This file is updated with a new entry as each activity is
completed, so it will grow over time rather than being a one-time
write-up.

Each entry captures the 5 W's of an incident (Who, What, When,
Where, Why), any tools involved, and additional notes or reflection
questions raised by the activity.
