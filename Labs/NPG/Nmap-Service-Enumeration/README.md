# Nmap Service Enumeration — NPG Lab

## Lab Overview

An authorized cybersecurity lab completed as part of my
offensive security training with Next Path Ghana (NPG).

## Objective

Use Nmap to perform service discovery and version enumeration
against a controlled laboratory target.

## Tools Used

- Nmap
- Kali Linux

## Tasks

- Identify open TCP ports
- Identify services running on discovered ports
- Perform service/version enumeration
- Analyze the results
- Use the findings to answer the lab's questions

## Key Findings

The scan identified several exposed services, including:

- FTP
- SSH
- SMTP
- HTTP
- HTTPS
- MySQL
- Redis
- HTTP proxy

The scan also identified filtered and closed ports.

## Analysis

Service and version detection provided additional information
about the technologies running on the target. This information
can be useful during the enumeration phase of an authorized
penetration test because it helps determine which services may
require further investigation.

## What I Learned

This lab helped me understand how service/version detection
can provide much more useful information than simply identifying
open ports.

I also learned how enumeration results can be used to guide
the next stages of an authorized security assessment.

## Ethical Considerations

This activity was performed against a controlled laboratory
environment provided for cybersecurity training. No unauthorized
systems were targeted.
